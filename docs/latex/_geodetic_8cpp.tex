Converts Cartesian coordinates to geodetic coordinates (longitude, latitude, altitude). 

This function transforms a position vector in Cartesian coordinates (ECEF) to geodetic coordinates (longitude, latitude, and altitude) based on the WGS-\/84 ellipsoid parameters. The conversion uses an iterative method to account for the Earth\textquotesingle{}s flattening.
