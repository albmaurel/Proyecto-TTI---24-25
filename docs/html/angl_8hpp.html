double angl ( Matrix vec1,
Matrix vec2 )

Calculates the angle (in radians) between two vectors.

This function computes the angle between two vectors using the dot product formula. If either vector has a near-zero magnitude, the function returns a predefined undefined value.

Parameters
vec1The first vector as a Matrix.
vec2The second vector as a Matrix.
Returns
The angle in radians between vec1 and vec2, or a large undefined value if the angle cannot be determined.
