Computes the Legendre polynomials and their derivatives.

This function calculates the associated Legendre polynomials (Pn,m) and their derivatives (dPn,m/dθ) up to a given degree (n) and order (m) for a specified angle (fi) in radians.

Parameters
nMaximum degree of the Legendre polynomials.
mMaximum order of the Legendre polynomials.
fiAngle in radians for which the polynomials are computed.
Returns
tuple<Matrix, Matrix> A tuple containing two matrices:
  • The first matrix contains the values of the Legendre polynomials.
  • The second matrix contains the values of their derivatives.
