tuple< double, double, Matrix &, Matrix & > AzElPa ( Matrix & s)

Calculates the azimuth and elevation angles, along with their partial derivatives, from a position vector.

This function computes the azimuth (Az) and elevation (El) angles based on the provided position vector s. It also calculates the partial derivatives of Az and El with respect to the components of s.

Parameters
sReference to a 3-element position vector (Matrix&).
Returns
A tuple containing:
  • Azimuth angle (double)
  • Elevation angle (double)
  • Reference to the partial derivatives of Azimuth with respect to s (Matrix&)
  • Reference to the partial derivatives of Elevation with respect to s (Matrix&)
